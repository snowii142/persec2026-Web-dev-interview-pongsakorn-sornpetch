# ข้อ 2: เรียงข้อมูลที่มีตัวอักษรและตัวเลข

## โจทย์

เขียนฟังก์ชันรับ array ของ string แล้วคืนผลลัพธ์ที่เรียงแล้ว โดยดูวิธีเรียงจากตัวอย่าง

```text
["TH19", "SG20", "TH2"]              => ["SG20", "TH2", "TH19"]
["TH10", "TH3Netflix", "TH1", "TH7"] => ["TH1", "TH3Netflix", "TH7", "TH10"]
```

## แนวคิด

ถ้าเรียงแบบข้อความปกติ `TH19` จะมาก่อน `TH2` จึงต้องแยกแต่ละค่าเป็น 3 ส่วนแล้วเทียบทีละส่วน:

1. ตัวอักษรนำหน้า เรียงตามตัวอักษร เช่น `SG` มาก่อน `TH`
2. ตัวเลข เรียงตามค่าตัวเลข เช่น `2` มาก่อน `19`
3. ข้อความต่อท้าย เรียงตามตัวอักษร ใช้เมื่อ 2 ส่วนแรกเท่ากัน

กติกาข้อ 3 ตัวอย่างไม่ได้แสดงไว้ จึงกำหนดเอง โดยค่าที่ไม่มีข้อความต่อท้ายมาก่อน เช่น `TH3` มาก่อน `TH3Netflix`

ฟังก์ชันคืน array ใหม่และไม่แก้ array ที่รับเข้ามา

**Complexity** (n = จำนวนข้อมูล, L = ความยาวของแต่ละค่า): Time O(L · n log n) เพราะแยกส่วนทุกครั้งที่เปรียบเทียบ, Space O(n · L) สำหรับ array ใหม่
