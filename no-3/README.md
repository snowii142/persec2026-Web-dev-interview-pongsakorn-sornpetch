# ข้อ 3: Autocomplete

## โจทย์

เขียนฟังก์ชัน `autocomplete(search, items, maxResult)` ค้นหาคำใน `items` ที่มี `search` เป็นส่วนหนึ่งของข้อความ โดยไม่สนตัวพิมพ์เล็กใหญ่ แล้วเรียงตามตำแหน่งที่พบ คือขึ้นต้นคำ กลางคำ และท้ายคำ จากนั้นคืนผลลัพธ์ไม่เกิน `maxResult` ตัว

```text
autocomplete("th", ["Mother", "Think", "Worthy", "Apple", "Android"], 2) => ["Think", "Mother"]
```

## แนวคิด

แบ่งงานเป็น 3 ขั้นตอนตามลำดับ:

1. กรองเฉพาะคำที่มี `search` โดยแปลงเป็นตัวพิมพ์เล็กก่อนเทียบ ผลลัพธ์ยังใช้คำตามต้นฉบับ
2. เรียงตามอันดับของตำแหน่งแรกที่พบ: ขึ้นต้น = 0, กลางคำ = 1, ท้ายคำ = 2
3. ตัดให้เหลือไม่เกิน `maxResult` ตัว

โจทย์ไม่ได้ระบุกรณีต่อไปนี้ จึงกำหนดเอง:

- คำที่อันดับเท่ากันคงลำดับเดิมจาก `items`
- คำที่พบหลายตำแหน่งดูจากตำแหน่งแรก เช่น `search = th` กับ `Mathbath` นับเป็นกลางคำ
- `search` ว่างถือว่าตรงทุกคำ จึงคืนคำตามลำดับเดิม
- `maxResult` เป็น 0 หรือติดลบคืน array ว่าง

**Complexity** (n = จำนวนคำ, L = ความยาวของคำ โดยนับการค้นหาในคำหนึ่งเป็น O(L)): Time O(L · n log n) เพราะหาอันดับทุกครั้งที่เปรียบเทียบ, Space O(n · L) จากการแปลงตัวพิมพ์เล็กและ array ผลลัพธ์
