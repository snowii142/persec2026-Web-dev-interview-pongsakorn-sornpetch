# ข้อ 4: เลขโรมัน

## โจทย์

เขียน 2 ฟังก์ชันสำหรับแปลงเลขโรมันรูปแบบมาตรฐาน ([Standard form](https://en.wikipedia.org/wiki/Roman_numerals#Standard_form)) โดยใช้สัญลักษณ์ `I`=1, `V`=5, `X`=10, `L`=50, `C`=100, `D`=500, `M`=1000

- `toRoman` รับ int แล้วคืน string เลขโรมัน
- `fromRoman` รับ string เลขโรมันแล้วคืน int

```text
1989 <=> MCMLXXXIX
2000 <=> MM
68   <=> LXVIII
109  <=> CIX
```

## แนวคิด

ทั้งสองฟังก์ชันใช้ตารางเดียวกัน เรียงจากค่ามากไปน้อย และรวมคู่แบบลบอย่าง `CM` = 900 และ `IV` = 4 ไว้ด้วย จึงไม่ต้องมีกรณีพิเศษสำหรับการลบ

- **`toRoman`:** ไล่ตารางจากค่ามากไปน้อย ถ้าค่าที่เหลือไม่น้อยกว่าค่าของสัญลักษณ์ ให้ต่อสัญลักษณ์นั้นแล้วลบค่าออก
- **`fromRoman`:** ตรวจรูปแบบด้วย regex ก่อน แล้วไล่ตารางเดิม ถ้าตำแหน่งปัจจุบันตรงกับสัญลักษณ์ ให้บวกค่าแล้วขยับตำแหน่ง

ค่าที่นอกรูปแบบมาตรฐานจะ throw error แทนการคืนค่าที่อาจผิด:

- `toRoman` รับเฉพาะจำนวนเต็ม 1–3999 ค่าอื่น throw `RangeError`
- `fromRoman` รับเฉพาะ Standard form ตัวพิมพ์ใหญ่ เช่น `IIII`, `IC`, `xiv` และ string ว่าง throw `SyntaxError`

**Complexity:** Time O(1), Space O(1) ทั้งสองฟังก์ชัน เพราะตารางมี 13 แถวคงที่ และเลขโรมันที่ถูกต้องยาวไม่เกิน 15 ตัวอักษร
