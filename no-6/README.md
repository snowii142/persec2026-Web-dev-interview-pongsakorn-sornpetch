# ข้อ 6: Tribonacci

## โจทย์

เขียนฟังก์ชันหาลำดับ [Tribonacci](https://mathworld.wolfram.com/TribonacciNumber.html) ซึ่งแต่ละตัวเกิดจากการบวก 3 ตัวก่อนหน้า โดยรับ 2 ค่า:

- ค่าเริ่มต้นเป็น array ของ int จำนวน 0–3 ตัว
- จำนวนสมาชิกที่ต้องการเป็น int ที่ไม่ติดลบ โดยนับรวมค่าเริ่มต้น

```text
f([1, 3, 5], 5)    => [1, 3, 5, 9, 17]
f([2, 2, 2], 3)    => [2, 2, 2]
f([10, 10, 10], 4) => [10, 10, 10, 30]
```

## แนวคิด

เริ่มจากค่าเริ่มต้น แล้วบวก 3 ตัวสุดท้ายเพื่อเพิ่มสมาชิกทีละตัวจนครบจำนวน

โจทย์ไม่ได้ระบุกรณีต่อไปนี้ จึงกำหนดเอง:

- ค่าเริ่มต้นไม่ครบ 3 ตัว นับตัวที่ขาดเป็น 0 เช่น `f([1], 5)` ได้ `[1, 1, 2, 4, 7]` และ `f([], 5)` ได้ `[0, 0, 0, 0, 0]`
- จำนวนน้อยกว่าค่าเริ่มต้น ตัดให้เหลือตามจำนวน เช่น `f([1, 3, 5], 2)` ได้ `[1, 3]`
- ค่าเริ่มต้นเกิน 3 ตัวหรือไม่ใช่จำนวนเต็ม, จำนวนที่ติดลบหรือไม่ใช่จำนวนเต็ม และผลรวมที่เกิน `Number.MAX_SAFE_INTEGER` จะ throw `RangeError`

**ตัวอย่างในโจทย์ที่ขัดกับกฎ:** โจทย์เขียน `[2, 3, 1, 6, 9, 16]` แต่ `3 + 1 + 6 = 10` จึงยึดตามกฎการบวก 3 ตัว และได้ `[2, 3, 1, 6, 10, 17]`

**Complexity** (n = จำนวนสมาชิกที่ต้องการ): Time O(n), Space O(n)
