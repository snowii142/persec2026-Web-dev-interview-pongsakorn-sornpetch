# ข้อ 1: ตรวจการเปิดปิดวงเล็บ

## โจทย์

เขียนฟังก์ชันรับ string ที่ประกอบด้วยตัวอักษร `(`, `[`, `{`, `}`, `]`, `)` แล้วตรวจว่าสัญลักษณ์เปิดปิดครบคู่หรือไม่

```text
"()"     => true
"([{}])" => true
"([)]"   => false
"{"      => false
```

## แนวคิด

วงเล็บที่เปิดทีหลังต้องถูกปิดก่อน จึงใช้ stack เก็บวงเล็บเปิดที่ยังไม่ถูกปิด

1. เจอวงเล็บเปิด ให้เก็บลง stack
2. เจอวงเล็บปิด ให้ดึงตัวบนสุดออกมาเทียบ ถ้าไม่เข้าคู่หรือ stack ว่าง ตอบ `false` ทันที
3. เมื่ออ่านครบ stack ต้องว่าง ถ้ายังเหลือแปลว่ามีวงเล็บที่ไม่ถูกปิด

โจทย์ไม่ได้ระบุกรณีต่อไปนี้ จึงกำหนดเอง:

- string ว่างตอบ `true` เพราะไม่มีวงเล็บค้าง
- ตัวอักษรอื่นนอกจากวงเล็บตอบ `false`

**Complexity** (n = ความยาว string): Time O(n), Space O(n)
