# ข้อ 5: เรียงตัวเลขจากมากไปน้อย

## โจทย์

เขียนฟังก์ชันรับ Positive Int แล้วเรียงตัวเลขแต่ละหลักจากมากไปน้อย จากนั้นคืนผลลัพธ์เป็น Int

```text
3008 => 8300
1989 => 9981
2679 => 9762
9163 => 9631
```

## แนวคิด

แปลงตัวเลขเป็นข้อความเพื่อแยกทีละหลัก เรียงจากมากไปน้อย ต่อกลับเป็นข้อความ แล้วแปลงเป็นตัวเลข การเรียงตัวเลขหลักเดียวแบบข้อความให้ลำดับเดียวกับการเรียงตามค่า

ค่าที่รับไม่ได้จะ throw `RangeError`:

- ค่าที่ไม่ใช่จำนวนเต็มบวก รวมถึง 0, ค่าติดลบ, ทศนิยม และ `NaN`
- ค่ารับหรือผลลัพธ์ที่เกิน `Number.MAX_SAFE_INTEGER` เช่น `1000000000000009` เรียงแล้วเกินค่าปลอดภัย จึงไม่คืนเลขที่คลาดเคลื่อน

ส่วนรับ input ใน `main.ts` รับเฉพาะข้อความที่เป็นตัวเลขล้วน ถ้าพิมพ์ผิดจะแสดงข้อความแล้วรับบรรทัดถัดไป

**Complexity** (d = จำนวนหลัก): Time O(d log d), Space O(d)

## วิธีรัน

```bash
pnpm tsx no-5/main.ts               # รับ input จากการพิมพ์ กด Enter ที่บรรทัดว่างเพื่อจบ
pnpm tsx --test no-5/index.test.ts  # รันชุดทดสอบ
```
